# サポート情報

いくメモを使っていて困ったときに読むページです。アプリの「設定」→「ご意見・ご要望」からも案内しています。
使い方の説明は [USER_GUIDE.md](USER_GUIDE.md)（アプリの「設定」→「使い方」と同じ内容）を見てください。

## よくある質問

### お知らせが来ません

次のことを確かめてください。

- 端末の設定で、いくメモの通知がオンになっているか。お知らせ画面の上に「通知がオフのため、お知らせが届きません」と出ているときは、
  そこの「通知をオンにする」から設定を開けます
- 電池の節約の設定で、いくメモが止められていないか。機種によっては「アプリの電池の使用量」などで「制限しない」にする必要があります
- 期限を決めているか。お知らせ画面の「最近買った物」で「期限を決める」を押すと、期限の前の日にお知らせします
- お知らせの時刻は、設定の「お知らせ」で確かめられます

端末を再起動したり電源を切っていたりした場合も、次に起動したときにお知らせを入れ直します。

### 声で入れられません

- マイクの使用を許可しているか確かめてください。断ったときは、端末の設定のアプリの権限から許可できます
- 周りがうるさいと聞き取れないことがあります。少しはっきり話してみてください
- 音声入力が使えない機種では、マイクのボタンが出ません。「文字で追加」で入れられます

### 機種変更のとき、データは引き継げますか

- メモ・記録・設定・背景の写真は、Android の自動バックアップで引き継がれます（端末の設定でバックアップがオンの場合）
- メモや記録に付けた写真は自動バックアップに含まれません。機種変更のときの端末同士のデータ移行で引き継げます

### ホーム画面に置くには

設定の「ホーム画面に置く」から置けます。置けないときは、ホーム画面の何もないところを長押しし、「ウィジェット」から「いくメモ」を選びます。
「話して追加」と「メモ一覧」の 2 種類があります。

### 家族とメモを共有できますか

できません。いくメモはアカウントやサーバーを持たず、メモは端末の中にだけ保存します。

## ご意見・不具合の送り方

アプリの「設定」→「ご意見・ご要望」から送れます。

- **GitHub で送る**：開発の記録を公開している GitHub の Issue として送ります。どなたでも見られる場所なので、
  お名前やメールアドレスなど、ご本人が分かることは書かないでください。アプリの画面の「この情報をコピー」で、
  アプリの版・Android の版・機種名を貼り付けていただくと、原因を調べやすくなります
- **ご意見フォーム（準備中）**：GitHub を使わずに送れる Google フォームを準備しています
- **ストアのレビュー**：Google Play のレビューにも目を通しています

個別のお返事はしていません。対応したことはリリースノート（[RELEASE_NOTES.md](RELEASE_NOTES.md)）でお知らせします。

### 脆弱性の報告

セキュリティ上の問題は、公開の Issue ではなく [SECURITY.md](../SECURITY.md) の方法で知らせてください。

## 対応の方針

- いただいたご意見は、開発者が週に 1 回ほど目を通し、GitHub の Issue にまとめます（運用は [FEEDBACK.md](FEEDBACK.md)）
- アプリの考え方（話すだけで手早くメモ、端末の中だけで完結）に合わないもの（家計簿・共有など）は、見送ることがあります
- 個人で開発しているため、対応の時期はお約束できません
