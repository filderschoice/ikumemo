# ご意見の受け付けと運用（オーナー向け）

利用者からの要望・不具合・質問を受け付け、GitHub Issues にまとめ、結果を知らせるまでの手順です（PLAN §7.3 の運用の正本）。
利用者向けの案内は [SUPPORT.md](SUPPORT.md)、個人情報の扱いは [store/PRIVACY_POLICY.md](store/PRIVACY_POLICY.md) に書きます。

## 考え方

- 最終的な置き場所は GitHub Issues に一本化し、判断と進み具合をそこで管理する
- 利用者の多くは GitHub を知らないため、慣れた方法（フォーム・ストアのレビュー）で送ってもらい、オーナーが個人情報を除いて転記する
- 連絡先は受け取らない（D-21）。個別の返信はせず、対応結果はリリースノートで全体に知らせる

## 受け付けの窓口

| 窓口 | 状態 | 内容 |
| --- | --- | --- |
| ご意見フォーム（主） | 受付中（2026-11-15 から。アプリの「ご意見・ご要望」→「ご意見フォームで送る」で開ける） | Google フォーム。アプリは転送ページ（GitHub Pages）を `?info=<版・Android の版・機種名をエンコードした文字列>` 付きで開き、転送ページがフォームの事前入力へ移し替える |
| GitHub Issues | 受付中 | アプリの「ご意見・ご要望」→「GitHub で送る」、または Issue テンプレート（`.github/ISSUE_TEMPLATE/`） |
| ストアのレビュー | 公開後 | Play Console で確認し、返信する |
| クローズドテスト | テスト期間中 | [CLOSED_TEST.md](CLOSED_TEST.md) に同じ窓口を載せる |
| ストアの連絡先メール | 公開後 | ご意見フォームを案内する定型文で返す。転記する場合は個人情報を除く |

## ご意見フォームの作り方（BL-087）

| 項目 | 設定 |
| --- | --- |
| 項目 | どんな内容ですか（こうして欲しい／うまく動かない／使い方が分からない／その他）、内容（自由記入、例文付き）、アプリの版・Android の版・機種名（自動記入・編集可）、公開についての同意（必須） |
| 同意の文 | 「いただいた内容は、お名前・連絡先を除いて、開発の記録（GitHub という公開の場所）に載せることがあります」 |
| ログイン | 「回答を 1 回に制限」をオフにし、Google アカウントにログインせずに回答できるようにする |
| メールアドレス | 収集しない。返信用の欄も設けない |
| 添付 | 求めない（Google フォームの添付はログインが必要になるため） |
| 回答の保存先 | オーナーだけが見られるスプレッドシート（共有は「制限付き」） |
| 自動記入 | 「事前入力した URL を取得」で各項目の `entry.<番号>` を調べ、転送ページに書く |
| 説明文 | 「どんなことでも大丈夫です」「お名前やメールアドレスなど、ご本人が分かることは書かないでください」「個別のお返事はしていません。対応したことはアプリの『新しくなったこと』でお知らせします」と、同意の文を載せる |

フォームの URL はアプリに書かず、転送ページ（`https://filderschoice.github.io/ikumemo/feedback`）だけを差し替える。

## 毎週の運用

| 手順 | 内容 |
| --- | --- |
| 仕分け | 週 1 回、フォームの回答・ストアのレビューを確認する |
| 転記 | 同じ内容の Issue があれば「+1」のコメントで件数を数え、なければ新しく作る。本文は要約して書き直し、原文をそのまま貼らない |
| 個人情報 | 自由記入欄に名前・連絡先などが書かれていたら転記せず、回答シートからも消す |
| ラベル | 種類 `type: 要望` / `type: 不具合` / `type: 質問`、出どころ `from: フォーム` / `from: レビュー` / `from: GitHub`、状態 `status: 検討中` / `status: 対応予定` / `status: 見送り`（Issue テンプレートと同じ半角コロンと空白。ラベルの作成は BL-009） |
| 判断 | PLAN §1 のコンセプトと §9「やらないこと」（家計簿・共有など）に照らす。見送る場合も理由を Issue に残す |
| お知らせ | 個別の返信はしない。対応した要望は [RELEASE_NOTES.md](RELEASE_NOTES.md) に「いただいたご意見から」と書く。ストアのレビューには Play Console から返信する |

## 自動化について

初めは手作業で行う（件数が少なく、個人情報の除去を人の目で確実に行うため）。件数が増えたら、フォームの送信から GitHub に
非公開の下書きを作る仕組み（Google Apps Script など）を検討する。
