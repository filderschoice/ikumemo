# リリースノート

いくメモのバージョンごとの変更点を、アプリを使う方に向けて記録します。困ったときは [SUPPORT.md](SUPPORT.md) を見てください。

## このファイルの位置づけ

| ファイル | 読む人 | 書くこと |
| --- | --- | --- |
| 本ファイル（`docs/RELEASE_NOTES.md`） | アプリを使う方 | バージョンごとの新しい機能・よくなったところ・直したところ・分かっている問題 |
| [CHANGELOG.md](../CHANGELOG.md) | 開発者 | リポジトリの運用ルール・ドキュメントの変更 |
| [docs/records/managed/EXECUTE.md](records/managed/EXECUTE.md) | 開発者・AI エージェント | コードの変更 1 件ごとの記録 |

## 書き方

- 新しいバージョンを上に足します
- 見出しは `## <バージョン>（<公開日>）` とします。まだ公開していないものは日付の代わりに「未公開」と書きます
- やさしい言葉で、使う方から見た変化を書きます。いただいたご意見から直したものには「いただいたご意見から」と添えます
- GitHub Releases の本文はここから写します

## 0.1.0（未公開）

初めての版です。

### できること

- 話すだけでメモ（「牛乳とたまご」で2つに分かれて入る、数も入る）。文字で入れることもでき、前に入れた物やよく買う物が候補に出ます
- 買ったら右へ、やめたら左へ動かして記録。品名の左の ○ でも「買った」にでき、間違えたら「元に戻す」で戻せます。「えらんで消す」で、いらない物をまとめて消せます
- メモを LINE などへ送れます。LINE などで受け取った買い物の文は、取り込んでメモにできます
- いつものお店を選んでおくと、買った記録にお店も残ります
- メモに写真を付けられます。「買った」にすると記録にも残ります
- 「記録」のカレンダーで、買った物を日付ごとに見返せます。品名で探す、後から記録する、記録を直す・消すこともできます
- 「期限」を決めると、前の日にお知らせします
- 設定から、メモ・買った記録・設定をファイルに書き出して、機種変更のときなどに読み込めます。データをすべて消すこともできます
- 設定の「ご意見・ご要望」から、ご意見フォームを開いて送れます（自分で送信したときだけ届きます）
- ホーム画面に「話して追加」と「メモ一覧」の2つのウィジェットを置けます。アイコンの長押しからもすぐ開けます
- 4つのテーマ、背景の写真、文字の大きさ、暗い画面を選べます
- 初めて使うときの案内と、その場のガイド、いつでも見直せる「使い方」があります
