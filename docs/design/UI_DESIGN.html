1. 概要と読み方

UI の現状を数分で把握するための 1 枚。

画面の絵はコードからの再現で、実機のスクリーンショットではありません。ただし 3.0 節の 3 枚は、 スクリーンショットテスト（Roborazzi）が Robolectric の上で実際の Compose のコードを描いた画像です（実機ではないため、端末ごとの違いは含まない）。文言は strings.xml、色と角の丸みは designsystem/ThemePreset.kt から生成時に読み込んでいます。 配置・余白は Compose のコードを読んで近づけたもので、実機と細部は異なります。アイコンは Material Icons の形の近似です （ウィジェットのマイク・キーボードとアプリのアイコンは res/drawable の pathData をそのまま使用）。 品名・お店・日付は説明用のサンプルです。

9. 所見

根拠のある事実と「未確認」を分けて書く。優先度付けと起票はしない。

実機で未確認画面は Robolectric の画面テスト・コントラストのテスト・スクリーンショットテスト（72 枚）で確認。実機での配置、ガイドの吹き出しの位置、背景の写真の見え方、ホーム画面アプリごとのウィジェットの大きさは未確認（人手検証として BACKLOG に残っている）。
未実装の UIPLAN の MVP の UI はすべて実装済み（「LINE などで送る」F-08 など S 以下の機能は対象外）。
動き初めての案内 1 枚目は「牛乳とたまご」が 2 つに分かれる手本を 3 回、G-03 は練習項目を右へ少し動かす手本を 2 回見せて止まる。端末の「アニメーションを減らす」では動かさない（R-56）。本書の絵は止まった最後の形。
アクセシビリティアイコンだけのボタンには説明を付け、色だけで伝えず文字を添えている（スワイプの背景、設定の ⚙ に文字）。メモの行は読み上げの操作の一覧に「買った」「やめた」を出す。TalkBack での実際の読み上げ順は未確認。
暗い画面のカレンダー端末は明るい設定・アプリだけ暗い画面のとき、曜日の色とお店の点が明るい画面用の色になる不具合があり、スクリーンショットテストで見つけて直した（LocalDarkTheme）。
ウィジェットの見出しメモ一覧（幅 250dp）の見出しは「いくメモ」「🛒メモ 5件」「🔔期限が近い 2件」を 1 行に並べるため、本書の再現では収まらず末尾が切れる。Glance では各文字が 1 行で、はみ出し方はホーム画面アプリの大きさと端末の文字サイズで変わる未確認。
ダークテーマ4 テーマとも暗い配色を持ち、ウィジェットにも反映する。Dynamic Color（おまかせ）は v1.x のため未対応。
アイコン画面内のアイコンは Material Icons（Rounded）。本書の絵は形の近似。
