# いくメモ プライバシーポリシー

制定日: 2026年10月25日
最終改定日: 2026年11月15日

いくメモ（以下「本アプリ」）は、個人の開発者が公開しているオープンソースの買い物メモアプリです。
本アプリ自体は通信しません。利用者が「ご意見・ご要望」のボタンを押したときだけ、端末のブラウザで外部のページが開きます
（下の「ご意見をお送りいただく場合」）。このページでは、本アプリが扱う情報と、その扱い方を説明します。

## 要点

- アカウントの登録はありません。サーバーもありません
- 広告・利用状況の解析・クラッシュの収集を行うツールは入っていません
- メモ・買った記録・写真・設定は、すべてお使いの端末の中にだけ保存します
- 本アプリはインターネットに接続する権限を持っていません

## 本アプリが扱う情報

| 情報 | 使い道 | 保存場所 |
| --- | --- | --- |
| 買う物のメモ（品名・数・メモ・買うお店） | メモの表示 | 端末の中 |
| 買った記録（品名・買った日・お店・数・メモ） | カレンダー・候補・お知らせ | 端末の中 |
| お店の名前 | お店を選ぶ候補 | 端末の中 |
| 写真（メモ・記録に付けたもの、背景の写真） | 銘柄の確認、見た目の変更 | 端末の中（本アプリ専用の場所） |
| 設定（見た目・お知らせの時刻など） | 設定の反映 | 端末の中 |

- 写真は本アプリ専用の場所に写しを作って保存します。そのとき、撮影場所などの情報（Exif）は消します
- 位置情報は使いません

## 音声入力について

「話して追加」などの音声入力では、お使いの端末に入っている音声認識サービス（多くの端末では Google のサービス）を使います。

- 本アプリは、端末の中だけで認識する方式を優先して使います
- 端末の中で認識できない機種では、音声認識サービスの提供元で処理されることがあります。その場合の扱いは、音声認識サービスの提供元のプライバシーポリシーに従います
- 本アプリは、声そのものを保存しません。認識された文字だけをメモに使います

## 本アプリが使う権限

| 権限 | 使い道 |
| --- | --- |
| マイク | 音声入力。初めてマイクのボタンを押したときにだけ許可を求めます。許可しなくても、文字ですべての機能を使えます |
| 通知（Android 13 以降） | 期限のお知らせ。初めて期限を決めたときに許可を求めます |
| 起動時の受信 | 端末を再起動したあとに、お知らせの予定を入れ直すため |

カメラ・写真・連絡先・位置情報・インターネットの権限は使いません。
写真を撮るときは端末のカメラアプリに、写真を選ぶときは端末の写真の選択画面に任せます。

## バックアップと機種変更

- 端末の設定で Android の自動バックアップがオンのとき、メモ・記録・設定・背景の写真は、お使いの Google アカウントのバックアップに含まれます。このバックアップは Android の仕組みで行われ、開発者は見られません
- メモや記録に付けた写真は、自動バックアップには含めません。機種変更のときの端末同士のデータ移行では引き継がれます

## ご意見をお送りいただく場合

本アプリ自体は通信しません。利用者が自分で「ご意見・ご要望」から送る操作をした場合だけ、ブラウザで外部のページが開きます。

- **ご意見フォームで送る場合**: 「ご意見フォームで送る」を押すと、本アプリはアプリの版・Android の版・機種名を URL に入れて、
  端末のブラウザで GitHub Pages の転送ページ（<https://filderschoice.github.io/ikumemo/feedback/>）を開きます。
  転送ページはそれを Google フォームの欄に事前入力した URL へ移ります。
  このため、ボタンを押した時点で、アプリの版・Android の版・機種名は、ブラウザがページを開く通信の URL に含まれて
  GitHub と Google に届きます（お名前・連絡先・メモの内容は含みません）。
  ご意見の内容は、利用者がフォームで送信したときだけ Google のフォームへ送られます。
  版などの欄は、送信の前に利用者が見て直せます。
  - フォームではお名前・メールアドレスを集めません。回答は開発者だけが見られる場所に保存し、
    内容はお名前・連絡先を除いて要約し、GitHub に載せることがあります。個別のお返事はしていません
  - 転送ページには、外部のスクリプト・アクセス解析・Cookie を置いていません。GitHub Pages と Google フォームでの扱いは、
    それぞれのプライバシーポリシーに従います
- **GitHub で送る場合**: GitHub（開発の記録を公開している場所）の Issue として、どなたでも見られる形で公開されます。
  お名前やメールアドレスなど、ご本人が分かることは書かないでください。
  アプリの版・Android の版・機種名は、利用者がコピーして貼り付けた場合だけ送られます

## メモを送る・受け取る

- **メモを LINE などへ送る**: 利用者が「送る」を押し、表示された送り先のアプリを選んだときだけ、買う物の一覧の文を、選んだアプリへ渡します。
  本アプリが文を送るのは端末の中の選んだアプリへだけで、その先の扱いは選んだアプリのプライバシーポリシーに従います
- **LINE などで受け取った文を取り込む**: ほかのアプリから本アプリへ共有された文は、端末の中だけで読み取ってメモに加えます。
  取り込んだ文を、本アプリがどこかへ送ることはありません

## 情報の削除

- 本アプリをアンインストールすると、端末の中のメモ・記録・写真・設定はすべて消えます
- アプリの「設定」→「データ」で、メモ・記録・設定・写真をファイルに書き出したり、書き出したファイルを読み込んだりできます。保存先と読み込むファイルは利用者が選び、本アプリが通信することはありません
- アプリの「設定」→「データ」→「データをすべて消す」でも、端末の中のメモ・記録・写真・設定をすべて消せます（元に戻せません）
- 本アプリにはアカウントがないため、アカウントの削除の手続きはありません

## 子どものプライバシー

本アプリは 13 歳以上の方を対象としています。子ども向けのサービスとしては作っていません。

## ポリシーの変更

本ポリシーを変える場合は、このページを更新し、変更の履歴を GitHub に残します。
