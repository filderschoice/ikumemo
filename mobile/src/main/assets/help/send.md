# メモを LINE などで送る・取り込む

<!-- try: memo -->

メモの今の中身を、文字にして LINE などへ送れます。家族への「これ買ってきて」に使えます。

- お店チップ（「買うお店を選ぶ」）の右にある、送るマークを押します
- 送るアプリの一覧が出るので、LINE などを選びます
- 送る文は「🛒いくメモ」の下に、「・牛乳 2本」のように 1 行ずつ並びます
- その時点の内容を送るだけで、あとから変えても相手の文は変わりません（同期はしません）
- メモが空のとき、「えらんで消す」の間は、送るマークは出ません

LINE などで受け取った買い物の文を、いくメモへ取り込むこともできます。

- LINE のメッセージを長押しして共有（または「その他」から共有）を選び、送り先の一覧から「いくメモに追加」を選びます
- 文が 1 行ずつ品物に分かれ、チェック付きの一覧で出ます。入れない物はチェックを外して「N つ追加する」を押します
- いくメモから送った文は、元の品物と数量に戻ります。ほかの文も、行の頭の「・」「-」「1.」などを外して品物にします
- すでにメモにある物は「メモにあります」と出て、最初からチェックが外れています
- 長すぎる文は先頭の部分だけを読みます（品物は 100 件まで）。取り込める物が無いときは、その旨が出るだけで何も入りません
