# データの書き出しと読み込み

<!-- try: data -->

設定の「データ」で、メモ・買った記録・設定をファイルに書き出したり、書き出したファイルから戻したりできます。

- 「データを書き出す（写真も含む）」：写真と背景画像も入れた、いくメモで読み込めるファイルを作ります。機種変更や、アプリを入れ直す前の保存に向いています
- 「ほかの形式で書き出す」：押すと、写真なしと表計算用の2つの書き出しが出ます
- 「データを書き出す（写真なし）」：写真を除いた、いくメモで読み込めるファイルを作ります
- 「買った記録を表計算用に書き出す」：買った記録だけのファイルを作ります。表計算ソフト（Excel など）で開けますが、読み込みには使えません
- 「データを読み込む」：いくメモで書き出したファイル（表計算用は除く）を選びます。今のデータはすべて、ファイルの内容に置き換わります
- ファイルの保存先と読み込むファイルは、自分で選びます。通信はしません
- 読み込めないファイルを選んだときは、今のデータは変わりません
