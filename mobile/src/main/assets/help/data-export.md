# データの書き出しと読み込み

<!-- try: data -->

設定の「データ」で、メモ・買った記録・設定をファイルに書き出したり、書き出したファイルから戻したりできます。

- 「データを書き出す（写真つき）」：写真と背景画像も入れた ZIP ファイルを作ります。機種変更や、アプリを入れ直す前の保存に向いています
- 「データを書き出す（写真なし）」：写真を除いた JSON ファイルを作ります
- 「買った記録を表計算用に書き出す」：買った記録だけの CSV ファイルを作ります。表計算ソフトで開けますが、読み込みには使えません
- 「データを読み込む」：書き出した ZIP か JSON のファイルを選びます。今のデータはすべて、ファイルの内容に置き換わります
- ファイルの保存先と読み込むファイルは、自分で選びます。通信はしません
- 読み込めないファイルを選んだときは、今のデータは変わりません
