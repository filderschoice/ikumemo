# 話して入れる

<!-- try: memo; guide: g02 -->

画面の下の 🎤「話して追加」を押して、買いたい物を話します。

- 「牛乳とたまご」のように続けて話すと、1つずつに分かれます
- 「牛乳 2 本」のように話すと、数も入ります
- 話し終わると確認のカードが出ます。押すと直せて、× で外せます
- 外したカードは線で消えて「↩ 戻す」が出ます。「戻す」を押すと入れ直せます
- 「3つ追加する」のように入れる数が出たボタンでメモに入ります
- 続けて入れたいときは「追加して、つづけて話す」を押します。確認したカードをメモに入れて、そのまま次を聞きはじめます（入れた件数が「2件追加しました」と出ます）。やめるときはシートを閉じるか、何も話さずに待ちます

初めて使うときは、マイクの使用を許可してください。
