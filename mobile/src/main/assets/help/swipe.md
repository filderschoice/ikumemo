# 買った・やめた（動かす）

<!-- try: memo; guide: g03 -->

メモの品名を指で動かします。

- 右へ動かすと「買った」。今日の日付で記録に残ります
- 左へ動かすと「やめた」。記録には残りません
- 直すシートの「メモから外す」でも「やめた」にできます
- まとめて消したいときは、メモの上の「えらんで消す」を押します。各行にチェックが付くので、消す物を押して選び、画面の下の「○件を消す」を押すと、まとめて「やめた」になります。動かして消すのは、この間はできません。やめたいときは、上の「えらぶのを終える」か、戻る操作です
- 途中まで動かすと、軽く震えて知らせます（設定の「操作とお知らせ」で止められます）
